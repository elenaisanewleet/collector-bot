# Картинки бота

`welcome.jpg` — баннер приветствия. Отправляется на `/start`; отсутствие файла
не ломает команду, приветствие уходит текстом (`app/bot/banner.py`).

`avatar.png` — аватар бота, 512×512. Ставится вручную через @BotFather:
`/setuserpic`. Телеграм режет аватар в круг, поэтому значимое живёт внутри
центральных 80% — углы не увидит никто.

`avatar.svg` — исходник аватара. Правится он, PNG пересобирается из него, иначе
через месяц исходника не найти:

```
chromium --headless --disable-gpu --hide-scrollbars --force-device-scale-factor=1 \
  --window-size=1024,1130 --screenshot=tall.png file://$PWD/avatar.svg
# верхние 1024×1024 обрезать и уменьшить до 512×512
```

Про сам рисунок. Лупа — проверка, ради которой бот написан; внутри стекла
фрагмент номерного знака с синим полем — то, с чего у эвакуаторщика начинается
должник. Знаки на номере не буквы, а их ритм: настоящий номер, пусть и
выдуманный, на аватаре не нужен. Палитра — та же, что у веб-отчёта
(`app/web/style.py`): синий `#1F4E9C` с российского номерного знака.
