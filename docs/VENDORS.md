# Вендоры: чем закрыть пункты ТЗ

Разведка от 08.09.2026. Для владельца — чтобы решать, и для разработчика —
чтобы не искать заново.

**Статус документа.** Разведка по пяти направлениям вернулась по четырём;
пятое (комплексные агрегаторы) не ответило и остановлено. Отдельная фаза
проверки каждого кандидата не выполнялась, поэтому ниже у каждого честно
проставлено, что подтверждено живым запросом, а что — только чтением сайта.
Цены, которых нет в открытом доступе, обозначены «по запросу»; выдуманных
цифр в документе нет.

---

## Вывод первым: остаёмся на NewDB

Главный вопрос разведки был такой: **есть ли вендор, который ищет банкротство
по ФИО без ИНН?** Если да — мост «паспорт → ИНН» становится не нужен, и
банкротство открывается на всех 2052 должников вместо 1300 с паспортом.

Ответ: **такие вендоры есть, но они стоят как банковская подписка.**

| Вендор | ИНН нужен | Цена |
|---|---|---|
| NewDB (сейчас) | **да** | **2 ₽ за обращение** |
| ЕФРСБ, официальный API | нет | по запросу; косвенный ориентир — сотни тысяч ₽/год |
| Контур.Фокус API | нет | по запросу, отдельный тарифный план |
| Casebook / ПравоДела | нет | по запросу, индивидуально |

При точечной работе — проверить конкретного человека и решить, взыскивать ли —
2 ₽ за обращение выигрывает у любого годового контракта с разгромным счётом.
Годовая подписка окупается при тысячах проверок в месяц, а не при десятках.

**Рекомендация: ничего не менять.** Мост «паспорт → ИНН» дешевле, чем уход от
него. К вопросу стоит вернуться, если проверок станет сотни в день.

## Банкротство

### ЕФРСБ, официальный API оператора

Оператор — АО «Интерфакс» (Приказ Минэкономразвития от 21.03.2011 № 121).

**Проверено живым запросом** на открытом демо-контуре оператора:

```
GET /v1/bankrupts?type=Person&name=Иванов Иван&limit=3&offset=0
→ HTTP 200, total = 93

+ &birthdate=1970-01-01 по «Иванов Иван Иванович»
→ total = 3
```

Обязателен **один из** `name` / `ogrnip` / `inn` / `snils` — то есть ФИО
достаточно. `birthdate` — необязательный фильтр поверх ФИО. В ответе приходят
ИНН и СНИЛС найденных должников.

Про тёзок: по одному ФИО — 93 совпадения, ФИО + дата рождения сузили до 3.
Дальше добивать адресом, он есть и в ответе, и в вашей выгрузке.

**Цена.** Публичного тарифа нет. Дословно из памятки подключения: «Для
компенсации затрат на техническую поддержку функционирования веб-сервиса
взымается плата, размер которой определяется в Договоре». Косвенный ориентир —
оператор публикует шаблон договора на соседний реестр, где стоимость 50 100 ₽
плюс НДС в квартал. **Это не тариф ЕФРСБ**, а порядок величины. Точную цифру
спрашивать на `help@fedresurs.ru`.

### Контур.Фокус, метод `/api3/personBankruptcy`

Юрлицо: АО «ПФ «СКБ Контур».

ИНН не обязателен. Параметры: `key`, `innfl`, `fio`, `birthDate`, `xml`.
Дословно из документации: «Можно указать либо ИННФЛ, либо ФИО с/без даты
рождения». Подтверждено на игровом стенде самого Контура.

Оговорка, которую Контур пишет сам: поиск по точному совпадению, и если в
источнике ошибка в дате рождения — результат не вернётся. Рекомендуют два
запроса на человека: сначала ФИО + дата, потом только ФИО. То есть закладывать
**два обращения на должника** и ручной разбор тёзок.

**Цена по запросу.** Метод не входит в основные тарифы, он в отдельном плане
«Банкротство физических лиц», цена которого не опубликована. Цифры у
реселлеров — не официальный прайс, на них бюджет не планировать. Запрашивать:
`focus-api@kontur.ru`.

### Casebook API 3.0 (бренд «ПравоДела»), вендор ПравоТех

ИНН не обязателен: «Обязательные параметры — ключ API и ФИО/или ИНН/или СНИЛС».
Дата рождения на входе **не заявлена** — разбор тёзок предполагается по адресу.
Это слабее ЕФРСБ и Контура. Цена индивидуальная, открытого прайса нет.

### Не подтверждено

**СПАРК-Интерфакс**, **Saby (СБИС)**, **Seldon.Basis** — в публичных описаниях
поиск банкротства физлица по ФИО с датой рождения не заявлен; акцент на юрлицах.
Проверять только напрямую у вендора.

## Исполнительные производства

### Официальный API ФССП — существовал, сейчас отключён

`api-ip.fssp.gov.ru`, метод `/api/v1.0/search/physical`. Принимал ФИО + дату
рождения + код региона, **ИНН не требовался никогда**. Был бесплатным с лимитами
(100 запросов в час, 1000 в сутки).

**Сейчас недоступен ни за какие деньги.** Техподдержка: `admin@fssp.gov.ru`.

### Публичный сайт fssp.gov.ru

Работает, бесплатен, ищет по ФИО + дате рождения, есть «Все регионы». **Но
только руками** — для программы закрыт.

### Сторонние API к ФССП

Есть сервисы с подтверждённым прайсом — например, **0,60 ₽ за успешный запрос**
плюс минимальный платёж 700 ₽/мес. Это в четыре раза дешевле NewDB.

**Что уточнить перед подключением:** на каком основании вендор отдаёт данные —
договор с ведомством или собственный сбор с публичного сайта. От ответа зависит
устойчивость: сервис, зависящий от чужой вёрстки, ломается при её изменении.

## Имущество (ЕГРН)

Подтвердилось то, что уже записано в `docs/INTEGRATIONS.md`:

* **по ФИО собственника не ищет никто и никогда** — ни Росреестр, ни любой
  посредник. Выписка о правах отдельного лица третьим лицам не выдаётся;
* доступна **выписка об объекте** — по кадастровому номеру или адресу.

У вас адреса есть на 2033 должников, с номером квартиры — на 1512. Метод
подключён через NewDB и работает.

Сервисы, обещающие «данные о текущем собственнике по ФИО», проверять не имеет
смысла: такой выписки не существует как продукта.

## БКИ: ответ окончательный — нельзя

Перечень получателей кредитного отчёта в ч. 1 ст. 6 ФЗ-218 **закрытый**, девять
пунктов. Взыскателя без согласия должника в нём нет.

| Кто может | Что получает |
|---|---|
| сам человек | всё |
| пользователь кредитной истории | только **с письменного согласия** субъекта |
| суд по делу в его производстве | всё, включая закрытую часть |
| ФССП | титульная и основная части |
| нотариус по наследственному делу | сведения о наследодателе |
| финансовый управляющий в банкротстве | титульная и дополнительная |

У эвакуаторной компании согласия нет и взяться ему неоткуда: должник ничего не
подписывал.

**Единственный законный путь** — ходатайство об истребовании доказательств в
уже возбуждённом гражданском деле: п. 4 ч. 1 ст. 6 ФЗ-218 плюс ст. 57 ГПК РФ.
Суду выдаются все части. То есть БКИ — не третий шаг проверки, а следствие
первого: сначала иск, потом истребование.

**Не работает:** адвокатский запрос — адвоката в перечне нет; ЦККИ без кода
субъекта — код формирует сам должник.

**И главное:** пункт ТЗ «БКИ — есть банкротство или нет» закрывается **не через
БКИ**, а через ЕФРСБ. Банкротство — открытый федеральный реестр, согласия не
требует. Оно у вас уже подключено.

## Что делать

1. **Ничего не менять.** NewDB за 2 ₽ выигрывает у всех при точечной работе.
2. **Спросить у NewDB оптовую цену** — на сайте сказано, что при объёме дают
   ниже 1 ₽ за обращение. Письмо на `access@newdb.net`.
3. **К ЕФРСБ и Контуру вернуться**, если проверок станет сотни в день: тогда
   годовой контракт с поиском по ФИО начнёт окупаться и снимет мост к ФНС.
4. **БКИ закрыть как вопрос** — до первого выигранного дела.
